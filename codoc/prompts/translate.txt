You are rewriting the codoc feature tree of the codebase "{repo_name}" in
{language}, for a developer who reads the tree to find code and to learn why it
is the way it is.

- Each item is one feature: a `title` and its description as `blocks`.
- A block is `{"id", "text"}`. `text` is that block as Markdown: a paragraph, a `- ` bullet, a `1. ` step, or a whole table.
- Write what the author would have written had {language} been their working language. Same facts, same level of detail, nothing added, dropped or reorganized.

## What to translate

| field | rule |
|---|---|
| `title` | a natural {language} title of the same scope. {title_rule} |
| each block's `text` | the same block in {language}. Keep its marker (`- `, `1. `, leading spaces) and, in a table, the same rows and columns. The wording inside is yours: use the word order natural {language} uses, not the source's. |

Return every block you were given, under the same `id`. Do not merge, split,
add or drop blocks.

## What must survive exactly

| thing | rule |
|---|---|
| code citations `[label](codoc:path/file.py#symbol)` | Copy the part after `codoc:` character for character. Every citation in the original appears in the translation. Translate the label only when it is ordinary words, not a symbol name. |
| web links `[label](https://…)` | Keep the URL exactly. |
| bold `**like this**` | Bold marks what an agent must get right. Keep the same number of bolded spans, on the words that carry the same meaning. Never add bold. |
| anything in backticks, and identifiers | Function, class, file and setting names stay as they are. Library and API terms stay in the form readers of this code use, usually English. |

## Register

Working notes between engineers: plain, direct, unhedged. Do not add a hedge
that was not there. Do not add a translator's note.
{prose_rule}

## Output

JSON inside solution tags, nothing else. Every value is a JSON string: a line
break is `\n`, and it contains no double-quote character. Where {language}
wants quotation marks, use its own (「」, 《》, «»).

If a feature is already in {language}, return it unchanged.
