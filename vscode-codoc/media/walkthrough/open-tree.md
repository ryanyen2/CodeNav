## Open your feature tree

codoc maintains a human-intent-level **feature tree** of your codebase — a navigable map where each node is a named unit of intent bound to the code that implements it.

Open it to:

- **Navigate** — jump from a feature to the code it owns (and back).
- **Author intent** — edit titles and descriptions directly; codoc keeps them in sync with the code.
- **Ask for work** — select a sentence and comment on it. A comment is a request the
  agent implements, scoped to the code that sentence cites; **Build it** starts the agent
  straight away.
- **Review** — accept or reject the tree changes codoc proposes, inline where they happen.

[Open your feature tree](command:codoc.open)
