Note on the filing backlog

The backlog stands at about three weeks. It has been growing since the first week of June, when two of the four clerks moved to the new intake team.

The intake team's own note put it plainly:

Nothing here is slow. Everything here waits.

I do not think this is a staffing problem so much as a sequencing one. Files are opened in the order they arrive, and a file that needs a second signature goes back to the bottom of the pile each time it moves. A file needing three signatures can wait a month for work that takes twenty minutes.

What I would try first is a separate queue for anything already part-signed, worked before new arrivals. That costs nothing and would, I think, clear most of the tail.

If that does not work, the honest answer is that we need a fourth clerk back.
