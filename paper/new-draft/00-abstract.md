# Abstract

Coding agents change systems faster than developers can track what was decided. We present codoc, a VS Code extension that maintains a feature tree synchronized in both directions with the code of a repository. Code changes appear as proposals requiring explicit verdicts. Tree edits become directives the agent carries out. An iterative design process across two versions and 24 participants revealed a threshold effect. After verifying a small number of features against the code and finding them accurate, developers stopped opening source files and reasoned from the tree alone. Below that threshold, the tool was ignored regardless of its capabilities. Above it, detection of problems in agent-generated changes improved and decisions persisted in a durable record where they had previously vanished into chat. The finding inverts conventional tool design. Investment in keeping the representation faithful matters more than investment in making it expressive, because a tool the developer does not trust is just another thing to verify.
